# AIスクール ウェブサイト制作 実装計画書

この計画書は、AI技術の習得だけでなく「仕事を獲得する武器」を身につけることを目的としたAIスクールのランディングページ制作について記述したものです。

## デザインコンセプト： 「熱血 × 未来への挑戦」
受講生の「本気」に応える、熱量を感じるデザインを目指します。

- **配色**: 
  - メインカラー：パッションレッド (#D90429) または ディープオレンジ
  - アクセントカラー：エネルギッシュイエロー (#FB8500)
  - ベースカラー：プロフェッショナルな印象のダークネイビー (#023047) とクリーンなホワイト
- **タイポグラフィ**: 力強く、視認性の高いサンセリフ体（Google Fontsの「Inter」や「Bebas Neue」など）
- **アニメーション**: スクロールに応じた力強いフェードイン、ホバー時のダイナミックな動き

## 構成案

1. **ヒーローセクション**: 「AIを武器に、自らの力で未来を掴め！」という力強いメッセージ
2. **背景・課題**: 「既存のスクールの限界（高い・稼げない）」を指摘し、本質的な課題を提起
3. **解決策・特徴**: 「スキル習得 × 集客の仕組み」の両立、手頃な価格設定
4. **習得スキル（3段階）**: 初級・中級・上級の明確なロードマップ
5. **講義の流れ**: 参加から卒業までのステップ
6. **料金プラン**: 各レベル20万円という明快な提示
7. **卒業後サポート（未来設計士）**: 長期的な伴走者としての未来設計士の紹介
8. **CTA**: 無料体験授業・セミナーへの誘導
